# Restaurant Reservation SPA

A modern, responsive Single Page Application (SPA) built with React for discovering restaurants and managing table reservations.

## 📌 Overview
This frontend project serves as the client-side interface for a restaurant reservation platform (Mizdooni). It features dynamic routing, state management, and seamless REST API integration for authentication, data fetching, and user interactions.

## 🚀 Key Features
* **Dynamic Routing:** Client-side navigation using React Router with parameterized URLs (`/restaurant/:id`).
* **Component-Based UI:** Reusable architectural components including Navigation Headers, Restaurant Cards, and Rating/Review Modals.
* **State & Auth Management:** Secure handling of user sessions via JWT tokens and React Context API.
* **API Integration:** Asynchronous data fetching (`fetch`/`useEffect`) for rendering live restaurant catalogs and user reservation histories.

## 🛠️ Tech Stack
* **Frontend:** React.js, React Router DOM, Context API
* **Styling:** CSS3 / Bootstrap
* **Tooling:** Create React App (CRA), npm
